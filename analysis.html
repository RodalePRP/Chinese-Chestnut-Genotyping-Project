For the project team: publishing results

Results are kept in the project Google Sheet, not in this public repository, so breeder permissions can be enforced:

  • Results – Structure tab: sample_id, group, PC1, PC2 (more numeric columns become selectable axes). Database trees follow their breeder's Genotype Visualization setting automatically. For samples not in the database (e.g. pilot trees) use the access column: blank = project team only.
  • Results – Diversity tab: group, n, Ho, He, F. Each row is project team only unless its access column says Research collaborators & NNGA members, which should be set only when every breeder in that group allows it.
  • Never commit raw genotype files or tree-level results to the GitHub repository.
